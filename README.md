# ConvenienceStoreSim

goal
- made in Godot
- historically accurate to November 1st, 1970
- You play the role of a weird convenience store owner who has no employees, lives in their store, and has the capacity for murder. While it is a sandbox, you have the soft goal of:
  - Not getting arrested
  - Not getting killed
  - Not getting your store shut down
- functionally hyper-realistic; many complex systems that interact with each other (https://www.youtube.com/watch?v=iCMA2jQsWxQ). the only thing that has no goal of being system-itized is the in-game character's knowledge, which is represented by the real life player
  - fully functional [Programma 101](https://en.wikipedia.org/wiki/Programma_101) in the back room because it's used for accounting, not checkout (home computers aren't a thing yet)
  - wellbeing system
    - nutrition
    - hygiene (clothes will soil, hands will get dirty which customers will dislike)
    - sleep
  - store maintenance system
  - store economy system
  - social reputation system
- graphics that are ok
